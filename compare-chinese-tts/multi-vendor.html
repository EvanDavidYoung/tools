About your API keys. Keys are kept in this browser's localStorage and are sent only to each vendor's own API endpoint, directly from this page — there is no backend and nothing is proxied or logged. That still means a key is sitting in browser storage on this machine and is visible to any script running on this page, so use restricted / low-quota test keys, and click Forget all keys when you're done.
