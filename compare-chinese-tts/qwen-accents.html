How dialects work here. Qwen-Audio-3.0-TTS advertises 20 Chinese dialect regions, but only one named dialect voice — longchuanshu_v3.6, Sichuan-accented. Everything else is reached by instruction control: you tell the model 请用河南话表达。 and it complies. Alibaba documents that mechanism, but not how it travels through OpenRouter, so this page tries it four different ways and lets you hear which one actually works. Run Probe first.
