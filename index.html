Tools

Small self-contained tools. Each one is a single HTML file — no build step, no server, no tracking. They read files you pick locally and never upload anything.

Transcript player

Load an audio file and its transcript JSON, then play them in sync with word-level highlighting. Handles CJK and English token spacing.

Climbing detection viewer

Load a climbing video plus pose-detection output and scrub a colour-coded timeline of detected segments, to check where the model got it wrong. Comes with a sample clip loaded in one click.

Room planner

Drag furniture around a to-scale floor plan of a room, Sims-style. Flags pieces that overlap, block a door swing or sit in front of a radiator, and shows the clearance to the nearest wall or piece. Saves in your browser; exports JSON or PNG.

Chinese shadowing

Read along with spoken Mandarin, word by word, in simplified or traditional. Loop a single sentence, or turn on shadowing mode and it pauses after each one for a set number of seconds so you can repeat it out loud. Four articles included.
